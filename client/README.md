# Panduan klien · Instalasi dan pengaturan

Petunjuk langkah demi langkah untuk **memasang dan menyambungkan** setiap cara koneksi: Cisco AnyConnect, Hiddify, ekstensi Proxy Web, OpenVPN, dan Privat (Tailscale), ditambah apa yang harus dilakukan kalau iOS tidak mengizinkan Anda memasang aplikasi, cara memasang Telegram / Discord, cara mengatur banyak perangkat sekaligus, dan apa yang harus dilakukan kalau software seperti Dropbox meminta proxy. Untuk memilih cara yang tepat, lihat [Cara koneksi mana yang cocok untuk situasi apa](../network/02-choose-your-connection-method.md); kalau sudah terpasang tapi tidak mau tersambung, lihat [Pemecahan masalah](../troubleshooting/).
